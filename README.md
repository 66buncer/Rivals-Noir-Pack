# Rivals Noir Pack

Отдельный рисованный чёрно-белый текстурпак для Roblox RIVALS: тушь, штриховка и серые заливки.

Проект на стадии планирования. Готовых текстур и установочного конфига пока нет.

[План разработки](PLAN.md)

Работа начинается с лобби, затем расширяется на карты, предметы, небо и доступные элементы интерфейса.
Существующий COMR Redux остаётся отдельным проектом.

Важно: монохромные текстуры сами по себе не гарантируют отсутствие цвета от освещения,
окраски деталей и программных эффектов. Полный монохром кадра требует отдельной проверки.

Репозиторий предназначен для публикации готовых файлов и конфигурации через GitHub raw.
Секреты API, токены и исходный игровой кэш не публикуются.
